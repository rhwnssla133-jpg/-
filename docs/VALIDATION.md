# 구현·검증 보고서

기준일: 2026-10-19. 배포 ZIP은 실제 `config.json`을 기준으로 생성한 **전화 문의 모드**입니다. 미확정 사업정보·개인정보 안내를 합성 값으로 채우지 않았습니다.

## 실행한 검사

- Python 빌드 검사 **7개 통과**: 기본 잠금, 준비 완료 시 Google iframe/CSP/SEO, 사업정보·Google 고지 누락 시 잠금, 잘못된 Google 주소 거부, 미확정 도메인 처리, 안전한 출력 폴더, 반복 빌드와 가짜 접수 성공 방지.
- 실제 생성된 `Code.gs`의 Google 서버 모의 검사 **11개 통과**: 행 저장/운영자 메일/중복 처리, 기존 시트 유지와 초기 비활성화, 두 스위치 확인, 익명 고객의 관리자 함수 호출 거부, 세션/동의/봇 항목 검사, 선택 미동의 제외와 수식 입력 방어, 메일 실패 보존·재전송, 전화/지역/날짜/길이 검사, 하루 상한과 재시도, 변경 내용 충돌과 직접 HTTP POST 거부, 렌더링·상태 정보에서 비밀값 제외.
- 실제 Chromium 브라우저 검사 **5개 묶음 통과**. Google의 중첩 iframe과 `google.script.run` 응답은 **모의 구현**으로 처리했습니다.
- 업로드 ZIP과 소스 ZIP 무결성, 정적 ZIP 최상단 `index.html`, 서버/비밀키 미포함 확인.

`artifacts/validation.json`에 이번 브라우저 검사 결과가 있습니다. 합성 활성화 설정은 임시 폴더에서만 사용하고 제거하며 공개 ZIP에는 들어가지 않습니다. 그림은 직접 작성한 SVG로 실제 작업 현장 사진이 아닙니다. 접근성 동작을 점검했으나 모든 보조공학·표준 준수 인증을 의미하지 않습니다.

## 실제 계정에서 남은 확인

1. `Code.gs` 전체 교체, 초기 설정/테스트 메일, 기존 Google 웹 앱의 **새 버전 배포**. 예전 JSON 수신자는 새 iframe 폼과 호환되지 않습니다.
2. 사업자 상세정보·담당자·현재 계약/약관·실제 Google 처리/국외이전 조건·정적 호스팅 안내 확정.
3. 확인한 설정으로 재생성한 ZIP 수동 배포. 도메인·동의문 버전은 Google 코드와 함께 일치시킴.
4. 로그인 없는 시크릿 창·모바일·인앱 브라우저·타사 쿠키 차단 환경에서 Google 문의창과 별도 문의창/전화 대안 확인.
5. 비민감 테스트 문의의 행·동의 기록·Gmail 수신/스팸 분류·알림 실패 재전송 확인 후 테스트 사본 삭제.
6. 일일 할당량·남용 제한·수동 삭제 절차와 담당자 운영.

Netlify ZIP 생성, GitHub 파일 배포, 사용자의 Netlify 공개 배포, Google 웹 앱 배포와 실제 Gmail 수신은 서로 다른 상태입니다. 모의 검사 통과를 실제 계정 연결 완료로 보고하지 않습니다.
