# 네이버 파워링크 연결 준비

광고를 누르면 Netlify 홈페이지로 이동하고 고객은 전화 또는 Google 문의창을 이용합니다. 이 저장소는 홈페이지와 문의 접수 코드를 제공하며 네이버 광고 계정 개설·캠페인 등록·심사·과금 설정을 실행하지 않았습니다.

## 연결할 홈페이지

현재 설정 주소는 `https://helpful-granita-0cfa57.netlify.app/`입니다. 다른 도메인으로 바꾸면 `config.json`의 `site.url`과 Google 스크립트 속성 `SITE_ORIGIN`을 함께 변경하고 홈페이지/Google 코드를 재생성·재배포합니다. 광고의 실제 연결 주소도 맞춥니다.

홈페이지의 상호·광주 지역·포장이사/일반이사/사무실이사·전화번호와 광고 문구가 일치하도록 구성했습니다. 모바일 전화 버튼은 `010-2543-2424`로 연결합니다. 실제 대표자·사업자등록번호·주소·허가정보를 제공하면 푸터와 방침에 반영됩니다. 미확정 항목은 현재 온라인 문의를 잠그는 조건입니다.

## 문구 초안

| 항목 | 내용 예시 |
| --- | --- |
| 제목 | 광주 이사 OK익스프레스 |
| 설명 | 포장이사·일반이사·사무실이사. 이사 조건을 확인하고 상담해 드립니다. |
| 검색어 후보 | 광주 포장이사, 광주 이사업체, 광주 사무실이사 |

광고 관리 화면에서 현재 글자 수·키워드 정책·증빙·업종 심사 기준에 맞춰 조정하세요. 제공된 ‘30년 노하우’를 광고에도 쓸 경우 실제 증빙 가능 여부를 확인합니다. ‘무조건 최저가’, ‘100% 보상’, 가짜 보험·후기·인증 문구를 추가하지 않았습니다. 심사 승인이나 특정 순위·성과를 보장하지 않습니다.

## 광고 개시 전 실제 확인

1. 휴대전화에서 광고 연결 예정 주소와 전화 버튼이 열리는지 확인합니다.
2. 실제 사업정보·보상/계약 안내·개인정보 처리와 국외이전 안내를 확정합니다.
3. Google 새 코드 배포와 ZIP 재업로드 후 비민감 테스트 문의로 **시트 저장과 Gmail 수신**을 각각 확인합니다. [연결 순서](GOOGLE-SHEETS.md).
4. 네이버 검색광고 계정에서 업체 정보·연결 URL·예산·노출 지역·시간·검색어를 설정하고 현재 심사 절차를 진행합니다.

전환 추적 태그는 넣지 않았습니다. 추후 광고 추적을 추가하면 실제 수집 항목과 개인정보/쿠키 안내를 검토하고, 전환은 저장 완료가 확인된 접수에만 연동해야 합니다. 광고 클릭만으로 고객명단에 기록하거나 접수 성공으로 집계하지 않습니다.

공식 참고: [네이버 검색광고](https://searchad.naver.com/). 이 환경에서는 현재 광고 관리 화면이나 심사 정책 원문을 확인하지 못했습니다.
